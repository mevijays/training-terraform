# GenAI for Terraform Engineers

A short, opinionated track on **generative AI** and **AI coding agents** for infrastructure engineers. Not on the exam — but very on the job.

## Why this folder exists

By the end of 2026, most professional Terraform code in the wild is touched by an AI assistant somewhere in its lifecycle. Engineers who understand what these tools *are* (and aren't) ship faster and avoid the failure modes.

## Module index

| # | Module | What it covers |
|---|---|---|
| 1 | [GenAI Fundamentals](01-genai-fundamentals.md) | What generative AI is, how it differs from "regular" ML, key terms |
| 2 | [LLMs Explained](02-llms-explained.md) | How a large language model actually works (intuition, not math) |
| 3 | [Coding Agents Overview](03-coding-agents-overview.md) | GitHub Copilot, Claude Code, Cursor, Google Antigravity, Windsurf — how they differ |
| 4 | [GenAI in Terraform Workflows](04-genai-in-terraform.md) | Practical use: drafting modules, reviewing PRs, generating tests, drift narratives |

## How to use this section

- Students: read in order. Each module is ~10-15 min.
- Trainers: use module 1 as a "before lunch" intro on day one, then weave examples from module 3 and 4 into the rest of the course.
