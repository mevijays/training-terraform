## Lab prerequisites checklist

Before module 1:

- [ ] Terraform 1.12+ installed (`terraform version`)
- [ ] Azure CLI installed and logged in (`az login`)
- [ ] AWS CLI installed and configured (`aws sts get-caller-identity`)
- [ ] HCP Terraform account created (https://app.terraform.io)
- [ ] VS Code + HashiCorp Terraform extension
- [ ] A scratch folder somewhere on disk for labs
